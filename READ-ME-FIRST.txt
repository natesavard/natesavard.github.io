NATE SAVARD — ONE UPLOAD, NO GITHUB ACTIONS

This package preserves your current home, Rebirth collage, clothing and Vault code and adds a shared navigation menu.
Primary destinations in order: HOME · REBIRTH · JEWELRY · VAULT · JOURNAL.

HOW TO INSTALL (one upload, one commit):
1. Extract this ZIP onto your computer.
2. Open https://github.com/natesavard/natesavard.github.io
3. Code → Add file → Upload files.
4. Select ALL FIVE files from this extracted folder (not the ZIP).
5. Commit changes ONCE. Existing files with matching names will be replaced.

No Actions, no workflow, no folders to create, no editing script references.
These files go straight in the main directory at the same level as index.html.

Files: ns-primary-navigation.js, ns-unified-drop.js,
ns-life-force-everywhere.js, site-bottom-nav.js, journal.html.

Important: This does NOT modify your existing homepage or Rebirth HTML.
It adds a menu through the scripts already included by those pages. GitHub Pages
and browser script caches may take time to refresh; use Ctrl+Shift+R.
